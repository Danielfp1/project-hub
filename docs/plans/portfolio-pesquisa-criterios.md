# Estudar como fazer um bom portfólio

**Task Notion:** [[Pesquisas 2.0] Estudar como fazer um bom portfólio](https://app.notion.com/p/dan-figueiredo/Pesquisas-2-0-Estudar-como-fazer-um-bom-portf-lio-3bb71e25165981f380b9ec18f07ac403)

## Objetivo

Identidade imediata: nome, papel e uma frase acima da dobra; o visitante entende quem você é em cerca de 5 segundos.
Curadoria, não catálogo: poucas peças fortes com contexto (problema, o que fez, stack), em vez de grid longo de links.
Hub coeso numa landing: uma página principal bem resolvida antes de multiplicar rotas vazias; o cartão Gravatar é âncora, não o site inteiro.
Prova técnica visível: cada peça mostra uma decisão (SSR, API, deploy), não só screenshot.
Consistência visual enxuta: paleta e tipografia restritas (Nord + Geist); animações sutis, sem ruído.

## Checklist

- [x] Abrir 3 portfólios que você respeita
- [x] Anotar 5 critérios (o que você vai copiar)

## Portfólios analisados

### [leerob.io](https://leerob.io)

Lee Robinson se apresenta num parágrafo: engenheiro e escritor, ML na SpaceX, passagem por Cursor e Vercel/Next.js, 15 anos programando e ensinando.

O que copiar:

- Identidade na primeira tela, sem hero genérico.
- Hub de links curados (crenças, DX, docs, software pessoal) em vez de dezenas de cards de projeto.
- Tom de pessoa, não de template (família, música, e-mail de advisory).

O que não copiar no project-hub agora: volume de essays. O hub ainda é um cartão de visita.

### [rauno.me](https://rauno.me)

Rauno Freiberg: “interaction designer working with Vercel”. Poucos projetos, manifesto curto (“Make it fast. Make it beautiful. Make it consistent…”).

O que copiar:

- Menos é mais: uma frase de papel + craft visível.
- Consistência e cuidado como produto, não decoração.
- Lista curta de peças, cada uma com peso.

O que não copiar: experimentalismo extremo de interação. O Gravatar + Nord já definem um visual sóbrio; o critério é não poluir.

### [itzkashan.dev](https://itzkashan.dev)

M. Kashan Ashraf, Next.js 16 + Tailwind v4 + Geist. Sobre, stack, 15 projetos (grid/lista), experiência, educação, blog, certificados.

O que copiar:

- Card de projeto com contexto (problema → o que fez → tecnologias), como em VizioRoom ou Share Pad (notepad só na URL, sem banco).
- Stack alinhada à do project-hub, static-first.

O que não copiar: catálogo de 15 peças, internships, CGPA e bookmarks. Isso vira currículo, não hub. A próxima task é escolher **3** peças, não listar tudo.

## Síntese para o project-hub

Hoje a home é só o cartão Gravatar. Os 5 critérios acima dizem o que acrescentar: uma linha de identidade além do cartão, depois no máximo três peças com prova técnica, na mesma paleta, sem novas rotas vazias.
